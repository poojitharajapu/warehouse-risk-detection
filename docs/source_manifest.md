# Source manifest

The project uses synthetic data only. No external dataset, service, credentials, or proprietary source code is required. Generator version is recorded as `0.1.0` in each output manifest; configuration, seed, row counts, schemas, and canonical SHA-256 hashes are included. Generation time is metadata and intentionally excluded from data hashes. The verified full baseline manifest is retained as [baseline_manifest.json](baseline_manifest.json); the generated CSV exports remain in the local ignored `outputs/` folder to keep large generated files out of Git.
